# ReactWoo Reviews — User Guide

## Install

1. Install the `reactwoo-reviews` zip (or copy the folder into `wp-content/plugins/`).
2. Activate **ReactWoo Reviews**.
3. Open **Reviews → Settings** and connect Google Business Profile (or enter free/pro license).

## Display reviews

- **Shortcode:** `[google_reviews]` (see admin Help for attributes).
- **Gutenberg:** insert **Google Reviews** block.
- **Elementor:** add **Google Reviews** from the Google Reviews category.
- **Widget:** Appearance → Widgets → Google Reviews.

## Updates

Updates are delivered from `api.reactwoo.com` (catalog slug `reactwoo-reviews`). Check **Dashboard → Updates**.

## Pro features

Activate a Pro or Enterprise license under **Reviews → License** to unlock advanced styles, multi-location, and analytics addons.
